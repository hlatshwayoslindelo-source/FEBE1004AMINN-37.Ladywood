Ladywood Dashboard Package

Upload all files in this ZIP to the MAIN page of your GitHub repository:

1. environmental_dashboard.py
2. requirements.txt
3. brownfield.xlsx
4. surface_water_flooding.json

What this version does:
- Brownfield reads from brownfield.xlsx.
- Surface-water flooding reads from surface_water_flooding.json.
- Air quality still updates online from Open-Meteo.
- Rainfall still updates online from Open-Meteo.

After uploading:
1. Click Commit changes on GitHub.
2. Go to Streamlit.
3. Click Manage app.
4. Click Reboot app.
5. Refresh the dashboard.
